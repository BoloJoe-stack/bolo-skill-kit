# 网页逐页整页截图（page-shot）

> 把一个"网页"按视觉上的"页"逐页截成**整页长图**——不用手工滚动、不用手工点 tab。

## 它解决什么

有两类网页，普通的截图工具搞不定：

- **交互式 HTML 报告**——内含多个 tab，靠点击切换，每层内容远超一屏
- **超长滚动页**——一张整页长图，不是一屏视口截图

这个 skill 做的就是：**自动判断有几"页"、自动切过去、每页出一张整页长图。**

## 核心方法

**第一步：拿到网页文件。** 本地 `.html`、在线地址，或挂在文档/云盘里的 HTML 附件（附录 A 讲了飞书的取法）。

**第二步：起本地服务。** 浏览器自动化工具通常**拦 `file://`**，本地文件必须起一个临时静态服务再开：

```bash
cd "<html 所在目录>" && python3 -m http.server 8765 --bind 127.0.0.1
```

**第三步：读结构决定怎么切页。** 找"这里有几页"的证据——页数提示（`L1 / 4`、分页圆点）、切换控件（tab、上一页/下一页、箭头）、内容高度。

看到页数提示但找不到切换控件 → **停下来问用户要几张，别瞎截。**

**第四步：逐页截图。** 切页 → 等稳定（有懒加载图要等图）→ 截图 → 下一页。

**第五步：互异性校验。** 各张图应**互不相同且非空白**——防"切页没生效，截出来全是同一页"。**这个问题肉眼翻图很难发现，必须机器判。**

## 几个实测踩出来的坑

**中文文件名 URL 编码极易漏字 → 404。** 稳妥做法是先取一次目录列表，把真实 href 拷来当 URL：

```bash
curl -s http://127.0.0.1:8765/ | grep href
```

**本地服务必须在 HTML 所在目录起**，否则 404。

**截图常默认落在会话当前目录** → 先建目标子目录，路径用相对子路径，不要传裸文件名。

**页面带固定 tab 头时，每张整页图都会含头部**——正常，不是 bug。

**tab 按钮里的 emoji 在终端显示乱码** = 控制台编码问题，**数据本身没坏**。

**停服务时别用 `taskkill python` 之类**——会误杀别的 python 进程。

## 附录 B：打印级 2x 高清

默认 1x 够网页/存档用。要打印/插图级时，**首选**在浏览器自动化里开一个 `deviceScaleFactor: 2` 的新页面再截整页（文本/矢量内容才能真正翻倍清晰）。

**退而求其次**（开不了新 context）：仍按 1x 截，再用 PIL `LANCZOS` 放大。
⚠️ 对文字类页面清晰度提升有限——**必须如实告诉用户。**

## 用法

```
"网页截图"   "截网页"   "截页面"   "把这个网页截成图"   "screenshot this page"
```
