# 网页逐页整页截图（page-shot）

将网页按视觉上的"页"逐页截取为整页长图，无需人工滚动或切换标签页。

## 功能定位

以下两类网页无法通过常规截图工具处理：

- **交互式 HTML 报告** —— 含多个标签页，须点击切换，且每层内容远超一屏
- **超长滚动页面** —— 需要整页长图，而非视口截图

本 skill 自动判定页面数量、逐页切换，并为每页生成整页长图。

## 处理流程

**第一步：获取网页文件。** 来源可为本地 `.html`、在线地址，或挂载于文档 / 云盘的 HTML 附件（飞书来源的获取方式见附录 A）。

**第二步：启动本地服务。** 浏览器自动化工具通常拦截 `file://` 协议，本地文件须经临时静态服务打开：

```bash
cd "<html 所在目录>" && python3 -m http.server 8765 --bind 127.0.0.1
```

**第三步：解析结构，判定分页方式。** 识别分页依据：页码标识（`L1 / 4`、分页圆点）、切换控件（标签页、上一页 / 下一页、箭头）、内容高度。

若存在页码标识但未找到切换控件，须暂停并向用户确认页数，不得凭推测截图。

**第四步：逐页截图。** 切换页面 → 等待稳定（含懒加载图片时须等待加载完成）→ 截图 → 切换下一页。

**第五步：互异性校验。** 各图应互不相同且非空白，用于防止"切换未生效、各页截图为同一内容"。**此类问题难以通过目视发现，须由机器判定。**

## 已确认的技术问题

**中文文件名 URL 编码易导致字符缺失并返回 404。** 可靠做法为先行获取目录列表，以真实 href 作为 URL：

```bash
curl -s http://127.0.0.1:8765/ | grep href
```

**本地服务须在 HTML 所在目录启动**，否则返回 404。

**截图默认输出至会话当前目录**，须先建立目标子目录，路径使用相对子路径，不使用裸文件名。

**页面含固定标签页头时，每张整页截图均包含该头部**，属正常现象，非缺陷。

**标签页按钮中的 emoji 在终端显示为乱码**，属控制台编码问题，数据本身未损坏。

**停止服务时不得使用 `taskkill python` 一类指令**，会误杀其他 Python 进程。

## 附录 B：打印级 2x 高清重截

1x 满足网页与存档用途。需要打印级或插图级质量时，**首选方案**为在浏览器自动化中新建 `deviceScaleFactor: 2` 页面后重新截图（文本与矢量内容可真正实现倍率翻倍）。

**备选方案**（无法新建 context 时）：仍按 1x 截图，再以 PIL `LANCZOS` 放大。
对文字类页面的清晰度提升有限，**须如实告知用户**。

## 触发方式

```
"网页截图"   "截网页"   "截页面"   "把这个网页截成图"   "screenshot this page"
```
