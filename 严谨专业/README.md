# 严谨专业

全局文体模式：回答、文档、网页文案、图表文字、代码注释一律改为严谨专业的书面语。

## 定位

把「写得体面」拆成可执行的规则，而不是依赖语感。本模式改的是文体，不改内容取舍。

触发后在整个会话持续生效，直到用户要求恢复正常。

## 适用与不适用

| 对象 | 是否适用 |
|---|---|
| 对话回答、文档、网页文案、图表文字、代码注释 | 适用 |
| 代码本身（标识符、字符串字面量、SQL、配置键） | 不适用，不得改写 |
| 用户原话、第三方原文、法规条款、报错原文 | 不适用，原样保留 |

## 规则构成

- 10 条文体规则：先结论后依据、直陈事实、术语一致、量化带口径、并列数值写方向与差值、不夸大、不确定即声明、一句一判断、禁口语与网络语、禁修辞与情绪符号
- 口语到书面语的对照表（12 组）
- 五类场景的正反例：对话回答、文档、网页文案、图表与表格、代码注释与提交信息
- 8 条自检清单
- 4 条破戒条款：紧急告警、用户要求原话、技术原文、极短文案的可读性权衡

## 已验证的边界

- 与「篇幅要求」的关系：篇幅由用户当面要求控制，本模式只管文体。两者冲突时保留口径，不因求短而删掉口径。
- 与既有文档的关系：文档既有标题与章节编号不得改写，改动会断链。
- 不适用的情形：代码与技术原文按原样保留，即使其中含口语或错字。

## 安装

```bash
cp -r 严谨专业 <项目目录>/.claude/skills/
```

重启会话后生效。

## 触发

`/严谨专业`、「严谨一点」、「专业一点」、「按书面语写」、「不要废话」。

关闭：说「恢复正常」或「关掉严谨专业」。
