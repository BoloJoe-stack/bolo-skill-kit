# 文档条目文献检索（lit-source-search）

为文档中有结论而缺依据的条目检索英文学术文献支撑。每轮仅处理一条，输出 5 篇候选后暂停等待选择。

## 功能定位

报告撰写中常出现如下情形：**结论已成形，但缺少文献依据**，一经追问即难以立足。

本 skill 将"补充文献依据"转化为可重复执行的流程。其核心特征不在检索技巧，而在**人机协作的节奏控制**。

## 两项基本规则

1. **每轮仅处理一条，输出 5 篇后暂停，等待用户指令，不自动进入下一条。**
2. **检索前先查询文献库。** 同一篇论文常可支撑多个条目，避免重复工作。

第一条为关键约束：输出量控制在"可一次完整阅读并作出判断"的范围内，避免一次性产生数十篇文献导致无法逐条甄别。

## 检索规范

从条目原文提炼 **3–5 组**英文检索词，覆盖三个维度：

1. **学理命名** —— 该现象在学术领域的标准称谓
2. **方法主线** —— 所属的成熟研究传统
3. **场景贴近** —— 研究对象所属行业或人群属性

三项已验证的限制条件：

- **不得使用日期排序。** 泛化关键词配合日期排序会返回大量无关领域的新近论文（实测某次泛化词的结果全部为工程与医学论文）
- **多词短语须加英文双引号**，否则会被拆解为宽匹配
- **须注意一词多义。** 同一词在不同学科含义不同（如 `segmentation` 在市场细分之外亦指图像分割）。命中领域不符时须立即更换检索词

**迭代规则**：某组检索词前 10 条中凡超过半数属于不相关领域，判定为无效检索词，立即更换，并记录本次试错。

## 筛选规范

按优先级选取：**领域对口 → 正规期刊优先 → 高被引优先 → 场景贴近优先**。

**不足 5 篇时**依次放宽条件（先降低被引要求，再放宽年份，最后纳入预印本），**并在文件中标注「降级收录」及原因**。

**不得静默降级。** 凡放宽条件均须明确记录。

## 产出文件

| 文件 | 内容 |
|---|---|
| `文献/第N题_*.md` | 本轮全部候选，以及全部检索式（含试错与被采纳的标识） |
| `信源记录/第N题_*.md` | 仅含入选文献，一条文献紧随一条对应结论 |
| `文献库/索引.md` | 全库总登记表，编号跨题连续，标注 `选中` / `备选` / `弃用` |

**「一条文献紧随一条结论」为格式要点**，不得拆分为"文献列表"与"结论列表"两个独立区块。文献信息使用英文，结论使用中文。

## 触发方式

```
"搜文献"   "找文献依据"   "查信源"   "文献溯源"   "给第 N 题找文献"
```

首次使用时，skill 将先确认目标文档与项目，随后建立目录结构。
