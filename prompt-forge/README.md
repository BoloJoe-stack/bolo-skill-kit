# prompt-forge

把口语化草稿改写成可直接执行的结构化提示词。

## 定位

适用于三类输入：无结构的草稿、模糊的任务描述、已存在但效果不佳的提示词。输出为可直接复制使用的完整提示词，并附待补信息与一句执行询问。

## 适用边界

- 处理对象：文本类与对话类提示词。
- 不处理：图像与视频生成提示词；提示词库管理与版本控制。
- 目标模型：未指定时按通用对话模型输出（Markdown 分节）；指定 Claude 或 Agent 场景时改用 XML 标签分节。

## 设计取舍

| 决策 | 原因 |
|---|---|
| 默认一次成稿、不追问 | 用户目标是完成任务，而非走完提示词写作流程；仅在目标无法推断时提一个问题 |
| 缺信息写 `{{待填：xxx}}` | 避免模型代拟事实，减少后续返工 |
| 约束必须可判定 | 「简洁一些」一类表述无法验收，改为字数、字段、条目数等可数标准 |
| 输出固定为三块 | 提示词、待补信息、执行询问，减少无关说明 |

## 组成

五种模式（默认改写、诊断、对比、系统、变量）、八段骨架、交付前四问自检。详见 `SKILL.md`。

## 安装

复制本目录至 `~/.claude/skills/`，或项目级 `.claude/skills/`。

## 已知限制

- 尚未进行跨模型实测，评分与对比结论未校准。
- 输入少于十个字且无上下文时，需要一次澄清。
